# CodePhone
Aplikasi Android (WebView) untuk membuka VS Code web: vscode.dev, github.dev, Codespaces, atau code-server milik sendiri.

## Build
1. Buka folder ini di Android Studio (Gradle wrapper dibuat otomatis).
2. Build > Build APK(s), lalu pasang APK di HP.

## Pilihan backend (tanpa laptop menyala)
- github.dev / vscode.dev : gratis, edit repo GitHub langsung dari HP.
- GitHub Codespaces : VS Code lengkap + terminal, berjalan di cloud.
- code-server di VPS : kontrol penuh. WAJIB pakai HTTPS + password kuat.
